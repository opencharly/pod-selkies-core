# 2026.242.1155 — fix: advance plugin-wl so the corpus resolves ONE version

## Summary

Advance the pinned `plugin-wl` from `v2026.237.1430` to `v2026.242.0610`, so the corpus resolves
**one** version of it.

**This is declarative alignment, not a behavioural change — and the distinction is load-bearing.**
`sdk/loaderkit/candy_version.go`'s `PickCandyVersion` is documented as *"the sole candy-version
arbiter — direct and transitive refs both flow through it"*, and it returns **one winner per bare
ref across the whole project**, newest-version-wins. So the moment any box in `distro-cachyos`
pulls `plugin-wl v2026.242.0610` (the new `box/cstream` does, through `pod-hyprland`), **this
candy is built against that version whether or not this pin moves**. Leaving the pin behind buys
nothing except a warning and a YAML file that describes a resolution charly is not performing:

```
Warning: candy github.com/opencharly/plugin-wl/candy/plugin-wl resolved to multiple versions;
         using newest 2026.242.0600 (from …@v2026.242.0610), ignoring 2026.187.1200 (from …@v2026.237.1430)
```

## What this candy inherits

- **Schema: purely additive.** Six `hypr-*` methods added to `#WlInput.method`; **nothing removed
  or renamed**, so every step this candy authors keeps its exact meaning.
- **Routing: B3's compositor capability table**, which this candy had not picked up (it predates
  `v2026.240.1326`). This is the real substance of the change — 204 of the differing lines are
  outside the Hyprland branches.
- The Hyprland dispatcher fix itself, which is inert here: `detectCompositor` routes by
  compositor, and this stack is not Hyprland.

## Change classification

**Change class:** candy/box-config — one pinned tag, one candy `version:`. No Go, no schema, no
workflow, single repo.

**Verification gate:** `check-selkies-labwc-pod` in `distro-cachyos`, run against a tree where the
new resolution is already in force — see below.

**Breaking change + rollback:** none to this candy's authored surface (additive schema). Rollback
is a plain revert and restores the warning without restoring the old resolution.

**Producer → consumer order:** satisfied — `plugin-wl v2026.242.0610` is merged and published.
